Help for volunteers

Use the formatting buttons above each text area for bold, italics, links and lists. Press Enter to add paragraphs. Use Move up and Move down to arrange sections. Duplicate makes a copy; Remove can be undone before publishing.

For events, choose Event card, add a poster and fill in the date, times and place. Events move into Past events automatically after their date. To hide an entry, select Hide section. Photos use Photo sections: upload, add a caption and describe the image for people using screen readers.

For the constitution, upload a PDF in the media library, then use its link in the About page's button. Next time, choose Replace file on the existing document to keep that link. Save draft does not change the public website. Preview shows your unsaved work. Publish changes saves it for everyone.

Use Restore a previous version to recover published text and layouts. Download a content backup regularly. Contact your website maintainer for full file recovery.
